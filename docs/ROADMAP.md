# PinOS Roadmap

This roadmap outlines the planned dveleopment of PinOS.

PinOS is currently in its early development, and things are subject to change and reconsideration.

## Completed

- [x] Initial Archiso profile.
- [x] Custom PinOS ISO identity.
- [x] XFCE desktop environment.
- [x] LightDM display manager.
- [x] Live user environment.
- [x] Sudo configuration.
- [x] Networking and DNS functionality.
- [x] Initial ISO build and UEFI testing.

- [x] Complete and publish the initial 0.1.0 prototype

## Planned

- [ ] Improve desktop configuration.
- [ ] Start the next prototype iteration.
- [ ] Expand build and testing documentation.
- [ ] Investigate installation options.
- [ ] Review live-user configuration.

## Future Considerations

- Peristent storage.
- ARM architecture support.
- Further system customisation.
- Additional hardware testing.
- Individual user account creation.
