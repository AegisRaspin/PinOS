# PinOS - Project Scope

## Included

PinOS aims to provide:
- An Arch-Linux-based distribution.
- A lightweight XFCE desktop environment.
- A terminal-focused computing experience.
- A carefully selected and tailored collection of applications and utilities
- A straightforward live environment
- A clean and consistent desktop environment

## Not Currently Included

The initial development scope excludes:
- A custom package manager.
- A completely independent package repository.
- A custom Linux kernel
- A custom desktop environment
- Secure boot for the (Initial) installation medium.

These exclusions may be reconsidered in future development.
